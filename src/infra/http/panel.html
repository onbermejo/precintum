Configuration in force

Shown so it can be audited, not edited. Changing configuration is the real attack surface, so it is changed in the deployment and never from a browser. Secrets are never sent here: of the private key, the deduplication key and the TSA password, only whether they are set.

Read-only by design. This panel serves only GET and HEAD requests and has no route that writes to the database. Exporting and closing batches are command-line operations. Operational key rotation is still planned.

No authentication. Whoever can open this port sees everything on this page. It binds to localhost by default; publishing it elsewhere requires putting a reverse proxy with authentication in front.
