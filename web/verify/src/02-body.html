    What this tool cannot verify

      Batches

      One row per hourly window. An empty batch is a heartbeat: it records a window with no registered verifications.

      Receipts

      Eight fields each, none of which identifies a person. The hash is recomputed here from the fields.

      Local verification. This page contains its own SHA-256 and BIP-340 Schnorr implementations, in plain JavaScript with no external libraries, so that verifying does not require trusting a download, a server or the operator. The code is part of the Precintum repository and a test in that repository cross-checks it against the server implementation on every run.

      Scope. These results concern the integrity and consistency of the delivered records. Authenticating the TSA timestamp and the Bitcoin anchor requires external validation. The checks do not prove that the recorded events happened or that all events were recorded; that requires independent checks and the operator’s responsibility.
